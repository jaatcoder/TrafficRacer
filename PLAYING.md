# How To Download And Play

This file is for players who just want to run the game.

## Option 1: Download Ready Build (Recommended)

1. Go to the repository Releases page.
2. Download the latest build zip for your OS.
3. Extract the zip.
4. Run the executable/app inside the extracted folder.

## Option 2: Build From Source (Needs Unity)

1. Install Unity 6000.3.9f1.
2. Clone the repository.
3. Open the project in Unity Hub.
4. Build from File -> Build Profiles.

## Notes

- If there is no release build yet, ask the maintainer to publish one.
- Source download alone is not directly playable without Unity build output.
